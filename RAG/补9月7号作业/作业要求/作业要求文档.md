接口要求
请使用 FastAPI 提供两个接口。

1. 构建知识库接口
POST /api/rag/build
功能：

读取图书馆服务文档
使用 RecursiveCharacterTextSplitter 切分文档
使用 OpenAIEmbeddings 将文档片段向量化
写入 Chroma 向量数据库
返回切分后的 chunk 数量
响应模型：

class RagBuildResponse(BaseModel):
    message: str
    chunkCount: int
示例响应：

{
  "message": "图书馆知识库创建完毕",
  "chunkCount": 9
}

{
  "query": "本科生一次最多可以借几本书？"
}
示例响应：

{
  "query": "本科生一次最多可以借几本书？",
  "answer": "根据图书馆服务指南，本科生一次最多可以借 8 本纸质图书，借期为 30 天。"
}
检索提示词如下：

prompt = ChatPromptTemplate.from_messages([
    ("system", """你是星河大学图书馆的新生咨询助手。
请严格根据下面提供的图书馆服务文档回答问题。
如果文档中没有相关规定，就回答“图书馆服务文档中未提及”，不要编造。

图书馆服务文档：
{context}"""),
    ("human", "{query}"),
])
